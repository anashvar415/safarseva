# 🏕️ SafarSeva – Hotel Booking Web App

**SafarSeva** is a full-stack hotel and stay booking platform that allows users to explore, list, review, and book properties. It includes a robust authentication system, image uploads, calendar-based bookings, and email notifications — all wrapped in a clean user interface.

## 🛠 Tech Stack

- **Backend**: Node.js, Express.js
- **Frontend**: EJS Templates, Bootstrap
- **Database**: MongoDB Atlas
- **Authentication**: Passport.js (Local & Google OAuth 2.0)
- **File Uploads**: Multer
- **Date Picker**: Flatpickr
- **Maps API**: Mapbox
- **Email**: Nodemailer
- **Deployment**: Render

---

## ✨ Features

### 👥 User Authentication
- Sign up and log in using email/password
- Google OAuth 2.0 login via Passport.js
- Secure session management

### 🏠 Listings
- Add new property listings with image uploads
- Edit and delete owned listings
- Display listing location using Mapbox
- Mark unavailable dates for each listing

### 🔍 Search & Filter
- Search listings by title or location
- Filter listings by category (e.g., Beach, City, Forest, etc.)

### 📅 Booking System
- Book listings by selecting dates via calendar (Flatpickr)
- Simulated payment confirmation
- View and manage bookings from user dashboard
- Listing owners can confirm, cancel, or delete bookings

### ⭐ Reviews
- Add star ratings and comments to listings
- Delete your own reviews

### ✉️ Email Notifications
- Booking confirmation and cancellation emails
- Forgot password email with secure reset link
